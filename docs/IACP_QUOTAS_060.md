# Registro histórico cerrado

La decisión definitiva del usuario confirma que IACP resolvió las cuotas comerciales históricas. Ese asunto está cerrado para IaCoC 0.6.0 y no es una dependencia pendiente.

Las observaciones anteriores fueron una captura temporal, superada por esa corrección. No se utilizan como configuración, validación, filtro ni límite de IaCoC. IaCoC no calcula cuotas, no condiciona creaciones a consumo acumulado y no impone máximos de instancias o planes. Cada intención nueva se envía al contrato de IACP con una clave nueva; el Control Plane conserva admisión, autorización, capacidad real e idempotencia.

No reabrir la investigación ni solicitar cambios de cuotas como prerrequisito de este frente. Mostrar únicamente los rechazos efectivos actuales del API con su diagnóstico.
