# Contratos consumidos para 0.6.1

IaCoC consume los contratos HTTPS existentes; no implementa rutas ficticias ni un ejecutor de infraestructura. No modifica IACP desde este repositorio.

| Capacidad                     | Endpoint real                                                                         | Permiso y estado                                                     | Evidencia / límite                                                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Catálogo                      | GET /v1/plans, /v1/images, /v1/profiles                                               | Identidad de lectura del tenant; comprobados                         | Cuatro planes/imágenes publicados; ningún CPU técnico en solicitud comercial                                                                    |
| Crear                         | POST /v1/instances                                                                    | operator del tenant + Administrator local; admitido real             | VM30030, operación f11b2f27-e19e-423b-87aa-abd08765a824; conformidad CPU no acreditada                                                          |
| Inventario/detalle            | GET /v1/instances?limit=100&offset=N; GET /v1/instances/{id}                          | Lectura tenant; comprobados                                          | 30030/30028 tombstones deleted; no modelo CPU/NUMA/BIOS expuestos                                                                               |
| Energía                       | GET /v1/instances/{id}/power; POST .../power/{start,shutdown,reboot}                  | Lectura / operator; backend IACP decide                              | INSTANCE_BUSY en apagado durante entrega; no se altera hardware                                                                                 |

Estados/precondiciones revalidados                                 |

| Hardware certificado/efectivo | No expuesto por el contrato consultado                                                | Pendiente IACP                                                       | Solicitar procedencia image_id→Golden certificada y modelo CPU/flags/NUMA/BIOS/machine observados; IaCoC solo compara y alerta                  |

CPU de VM30030 y el fallo de eliminación de VM30029: investigar en el frente IACP usando UUIDs/operaciones de STATUS_061.md. No se prescriben overrides técnicos en el cliente ni bypass de postcondiciones. Las cuotas comerciales históricas están cerradas y no son una dependencia de IaCoC.

Para nuevos contratos de lectura: tenant explícito acreditado, autenticación reader/operator por finalidad, sin secretos/cuerpos de credenciales; observed_at/TTL, no ceros para señales ausentes, paginación estable, 401/403 sin snapshots, 429 con Retry-After y 503 explícito. El mapeo de imagen y el hardware esperado/observado deben provenir de IACP; IaCoC no infiere la plantilla por nombre ni recursos.

Cobertura integral actualizada: [API_COVERAGE_061.md](API_COVERAGE_061.md). Existe retry-provision de planificación con expected_attempt, integrado en GUI/BFF con confirmación y precondiciones; no es un retry genérico de mutaciones ni un bypass de ejecución consumida. Red/access/provision se integraron con los contratos publicados y solo se ejecutaron contra dobles aislados en esta ampliación.
