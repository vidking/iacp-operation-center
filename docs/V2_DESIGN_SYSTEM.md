# Design system Glass V2

Definimos una identidad original con superficies translúcidas, bordes
discretos, profundidad suave y navegación flotante. Conservamos el nombre
Infrastructure as Code Operation Center y el isotipo IACP.

Graphite Glass usa grafito profundo y acentos eléctricos. Glass Light usa una
base cálida, marfil, grafito, azul y naranja. Ambos temas comparten componentes
y tokens CSS; no duplicamos páginas ni estilos.

Las animaciones se limitan a entrada, opacity y transform. Respetamos
prefers-reduced-motion y no mantenemos blur o WebGL animado permanentemente.
